# Paper-faithful baseline adaptations

These implementations intentionally consume the AST/CFG/DDG graphs exported by
this repository. They do **not** claim to be unmodified executions of upstream
repositories, because the parser, graph construction, benchmark splits, and
pair evaluator are controlled here. They preserve each method's defining logic:

| Method | Adapted logic | Project input |
|---|---|---|
| DECKARD | rooted AST-subtree characteristic vectors, size filtering, vector similarity | exported AST |
| ASTNN | statement-subtree recursive encoding, BiGRU, temporal max pooling | exported AST |
| RtvNN | recursive tree/vector encoding plus reconstruction loss | exported AST |
| CDLH | left-child/right-sibling AST, binary Tree-LSTM, supervised hash and quantization loss | exported AST |
| DeepSim | CFG semantic matrix with instruction-category and structural features | exported CFG |
| FA-AST+GGNN | relation-aware gated propagation | merged AST + CFG + DDG |
| FA-AST+GMN | the same flow-augmented graph plus cross-graph matching attention | merged AST + CFG + DDG |

For DECKARD, corpus-wide LSH candidate generation is unnecessary because the
benchmarks already supply candidate pairs. The evaluator retains subtree
characteristic vectors and the size/distance filter, and computes the closest
eligible subtree match directly.

Any previous result generated by the older “style” notebooks is stale after
this change and must not be mixed with results from these adaptations.
