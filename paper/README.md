# Paper artifacts

- `spectra_manuscript.tex` is the active article manuscript.
- `spectra_siam_methodology.tex` documents the original hybrid architecture before the spectral-only readout revision.
- `attributed_graph_spectral_method_comparison.tex` is the Persian implementation-aligned comparison of the legacy hybrid readout, the adjacency-only diagnostic, and the revised attributed graph-spectral readout.
- `cas-refs.bib` and `figures/` are shared publication inputs.
- `results.tex` contains generated publication tables.
- `archive/` contains unrelated or superseded manuscripts retained for provenance.

Compiled documents belong under `output/pdf/`; LaTeX auxiliary files and page
renders are temporary and should not be committed.
